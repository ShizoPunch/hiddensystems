Privacy Policy

Last updated: October 29, 2026

"hidden-systems-uploader" is a private tool used only by the owner of the Hidden Systems Inside YouTube channel. It is not offered to the public.

What it accesses

With the owner's permission, the tool uses the YouTube Data API and YouTube Analytics API to upload videos, edit video titles, descriptions and playlists, and read the channel's own analytics.

What it stores

The sign-in token is stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. No data from other users is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time at myaccount.google.com/permissions.
